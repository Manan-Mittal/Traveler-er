# Traveler-er

A trip planner where every day is a walkable zone on the map. Plan spots by neighborhood,
see realistic walk and transit times, track what needs booking, and get local picks
instead of the same viral list everyone else gets.

See [docs/PLAN.md](docs/PLAN.md) for the build plan, [docs/AI-PLANNER.md](docs/AI-PLANNER.md) for how the multi-agent planner works, [docs/DEPLOY.md](docs/DEPLOY.md) to deploy, and [docs/SECURITY.md](docs/SECURITY.md) for how sign-in and data are protected.
